* **Networking:** 
* **Storage:** Local SSD (it will update for RAID)

The following services are currently deployed and managed within this lab:

* **Virtualization/Containerization:** Docker & Docker Compose
* **Network Management:** Marzban Panel & WireGuard VPN
* **DNS & Security:** Cloudflare integration for domain management
